### 問題、修正與複驗

- 初次將整份 HTML 置於 PowerShell 指令時，Windows 拒絕建立程序，錯誤碼 206。改以檔案補丁寫入並替換目標。瀏覽器實際載入完成的 HTML 並通過測試。
- 草稿的 D1、D2 只指定區域日，練習回答卻包含具體天序。補上「第一天」與「第二天」，讓文件直接支持練習中的天序。實測提交正解及錯答，兩類回饋均正確。
- 靜態腳本最初只接受單一 `slide` 類別，漏計另有 `cover` 類別的封面。更新選取條件，並將每頁共同的對應表入口獨立於逐頁證據清單檢查。複驗正確識別九頁。

技術內容沿用已驗收的五篇論文及 Wiki。虛構文件、行程、分數與預約條件僅供教學。Chunking 策略比較仍待補證。
