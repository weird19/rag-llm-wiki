# S02 · Karpukhin 等人的 DPR 論文

## 原始資料

論文發表於 EMNLP 2020。本頁引用 2020-09-30 修訂的 [arXiv v3](https://arxiv.org/abs/2004.04906v3)，於 2026-11-22 從 [arXiv 全文 PDF](https://arxiv.org/pdf/2004.04906v3) 取得。本機保存的原件共 13 頁。頁碼依該 PDF，來源版本 ID 見[清冊](../source-catalog.md)。

## 摘要與適用條件

作者研究只靠學得的稠密向量，能否為開放域問答有效找出候選段落，並以 BM25 作為比較基準。[S02，§1，頁 1–2](#evidence-01) 實驗以英文維基百科為語料，測試五個開放域問答資料集。資料集與訓練設定會影響結果。[S02，§4–5.1 與表 2，頁 4–5](#evidence-04)

## 證據定位

<a id="evidence-01"></a>

- **S02，§1–2，頁 1–2**：開放域問答的檢索器從大型語料找出少量候選，再交給閱讀器。作者探討以學得的向量做段落檢索的可行性。

<a id="evidence-02"></a>

- **S02，§3.1，頁 2–3**：兩個獨立的 BERT 編碼器分別把問題和段落映射成稠密向量，以內積作為相似度分數。段落向量事先算好並建立 FAISS 索引。查詢時編碼問題，取回分數最高的 K 個段落。

<a id="evidence-03"></a>

- **S02，§3.2 與 §5，頁 3–5**：訓練提高相關段落相對於負例的分數。主要實驗重用同批其他問題的正例，並為每個問題加入一個 BM25 找到、但未包含答案的高分段落作為負例。

<a id="evidence-04"></a>

- **S02，§4–5.1 與表 2，頁 4–5**：語料取自英文維基百科，段落採不重疊的 100 詞區塊。Top-20 檢索命中率以題目為單位，計算前 20 段至少有一段包含答案的題目比例。單資料集訓練的 DPR 在 Natural Questions 為 78.4%，Lucene BM25 為 59.1%。在 SQuAD，同一比較是 63.2% 與 68.8%。這些數字衡量段落檢索。

<a id="evidence-05"></a>

- **S02，§6.1–6.2，頁 7–8**：端到端系統把檢索到的段落交給閱讀器挑選答案文字片段，並另外以答案的 Exact Match 評估整體問答表現。
