# S01 · Lewis 等人的 RAG 論文

## 原始資料

論文發表於 NeurIPS 2020。本頁引用 2021-04-12 修訂的 [arXiv v4](https://arxiv.org/abs/2005.11401v4)，於 2026-11-22 從 [arXiv 全文 PDF](https://arxiv.org/pdf/2005.11401v4) 取得。本機保存的原件共 19 頁。頁碼依該 PDF，來源版本 ID 見[清冊](../source-catalog.md)。

## 摘要與適用條件

作者研究如何把模型參數中的知識與外部文字索引結合，用於知識密集型任務。[S01，§1，頁 1–2](#evidence-01) 實驗涵蓋開放域問答、生成式問答、Jeopardy 問題生成與事實驗證。[S01，§3，頁 4–5](#evidence-04)

## 證據定位

<a id="evidence-01"></a>

- **S01，§1 與圖 1，頁 1–2**：純參數式模型在沒有外部記憶時，依賴訓練所得的模型參數。論文的 RAG 將這類生成模型與可檢索的外部索引結合，為當前輸入取得額外上下文。

<a id="evidence-02"></a>

- **S01，§2、§2.2–2.3，頁 2–3**：DPR 根據輸入從維基百科的稠密向量索引找出排名前 K 的段落。BART 把原始輸入與每個候選段落組合，並依該上下文估計輸出的機率。這是該論文的元件選擇。

<a id="evidence-03"></a>

- **S01，§2.1，頁 3**：RAG-Sequence 對每個候選段落計算整段輸出的機率，再按檢索權重加總。RAG-Token 在每個輸出 token 的機率計算中加總候選段落的貢獻，使用輸入檢索得到的同一組候選。

<a id="evidence-04"></a>

- **S01，§3，頁 4–5**：四類實驗用來比較不同形式的知識使用，包括生成答案、生成問題與輸出驗證標籤。

<a id="evidence-05"></a>

- **S01，§4.2 與表 2，頁 6**：在 Open MS-MARCO NLG 測試中，RAG-Sequence 的 ROUGE-L 為 40.8，BART 基線為 38.2。這是該任務的文字生成評分，回答的事實正確性仍需依具體證據判斷。作者也指出，部分題目需要指定的參考段落，且部分題目無法僅靠維基百科回答。
