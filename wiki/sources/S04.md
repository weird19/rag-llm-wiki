# S04 · Es 等人的 Ragas 論文

## 原始資料

本頁引用 2025-04-28 修訂的 [arXiv v2](https://arxiv.org/abs/2309.15217v2)，於 2026-11-22 從 [arXiv 全文 PDF](https://arxiv.org/pdf/2309.15217v2) 取得。本機保存的原件共 8 頁。來源版本 ID 見[清冊](../source-catalog.md)，頁碼依本機 PDF。

## 摘要與適用條件

作者面向缺乏標準參考答案的 RAG 評估情境，從問題、取回的上下文、生成答案估計三種品質。論文使用 LLM 提示評估，並用人工成對偏好檢驗指標表現。[S04，§3，頁 2–4](#evidence-01) [S04，§4–5，頁 4–5](#evidence-05)

## 證據定位

<a id="evidence-01"></a>

- **S04，§3，頁 2–4**：三個面向是 Faithfulness、Answer Relevance、Context Relevance。論文實驗的評估提示使用 gpt-3.5-turbo-16k。計分以當次輸入與輸出為依據，可在缺少人工參考答案時使用。

<a id="evidence-02"></a>

- **S04，§3，頁 3**：Faithfulness 衡量答案主張能否由給定上下文推得。先用 LLM 將答案拆成主張，再逐項判定上下文是否支持。分數為支持主張數除以主張總數。

<a id="evidence-03"></a>

- **S04，§3，頁 3，式 1**：Answer Relevance 衡量答案是否適切回應原問題。讓 LLM 從答案反向產生多個可能的問題，使用 text-embedding-ada-002 將問題嵌入，以各生成問題與原問題的平均餘弦相似度計分。這項指標的目的是衡量切題程度，未評估事實正確性。

<a id="evidence-04"></a>

- **S04，§3，頁 3–4，式 2**：Context Relevance 衡量提供的上下文是否聚焦。讓 LLM 從上下文抽取回答所需的關鍵句，分數為抽取句數除以上下文總句數。這項指標以降低冗餘資訊為目的。

<a id="evidence-05"></a>

- **S04，§4–5 與表 1，頁 4–5**：WikiEval 從 50 個維基百科頁面建立案例，由兩位英文流利的標註者比較兩個答案或兩份上下文。Ragas 在三項指標與人工偏好的一致率依序為 0.95、0.78、0.70，各項高於論文中的 GPT Score 與 GPT Ranking 基線。這是特定資料集的成對判斷一致率。作者也觀察到，評估模型在長上下文中較難辨出關鍵句。
